# Context Trainer v0.7.1

Geode-мод для Geometry Dash с тренировкой по методу «Контекст». Английский интерфейс ведёт через три шага: Choose starts → Learn the level → Train.

Windows x64, Geometry Dash 2.2081, Geode 5.10.1. Проект первоначально создан через `geode new D:/Dev/aitzkrieg`; ID `zhulis.context-trainer`.

## Как начать

1. Открой уровень и нажми **Pause → круглая иконка с мятным кубом и сиреневой стрелкой** в правом ряду кнопок.
2. Нажми **Choose starts** и отметь стартовые позиции. Можно нажать **All** или **None**. В длинном списке работает прокрутка; нажимать можно на всю строку.
3. **Start first pass** сразу закрывает меню и запускает практику. Отдельный Resume не нужен.
4. Один раз пройди каждый отмеченный участок до следующего выбранного старта. Последний участок заканчивается настоящим финишем. Смерть повторяет текущий участок.
5. После всех участков начинается тренировка. Главный экран показывает следующий диапазон и цель; **Train now / Continue training** сразу возвращает в игру.

Если план уже существует, открывается его текущее состояние. Планы и результаты v0.2.1 и новее совместимы, начинать заново не требуется. Сохранённый план открывается на паузе. При полностью пройденной диагностике **Start training** строит план без повторного прохождения. Планы v0.2.0 нужно создать заново; история прежних участков сохраняется.

Без StartPos можно тренировать весь уровень от 0%. Для коротких участков добавь стартовые объекты в локальную копию. Поиск использует способ Blitzkrieg 2.1: X / длина уровня. Мод не создаёт объекты уровня.

## Что находится на экране

- **Главная:** текущий этап, число пройденных участков, следующий диапазон, цель и одна основная кнопка.
- **All runs:** список участков; в первом проходе видны Passed / Current / Waiting, в тренировке можно включать нужные задачи.
- **Pace:** минимальное время на один участок и настройки напоминаний о перерыве.
- **Next run:** перейти к другой задаче, не дожидаясь минимального времени.
- **Original level:** необязательная связь оригинала с этим планом для общей статистики обычных попыток с нуля. Можно продолжать играть с нуля в SP-копии.
- **Pause plan:** останавливает автоматическую тренировку с сохранением результатов.
- **Change starts:** позволяет подготовить новый выбор. Замена существующего плана требует подтверждения Start over и повторяет первый проход.
- **Stats → Level map:** карта смертей по участкам в 5% и данные первого прохода. Это диагностика, а не оценка готовности.
- **Stats → Run progress:** показывает, какие участки становятся надёжными. Есть понятный счётчик вроде `2 passed / 7 attempts` и последние шесть исходов **Pass / Fail**, новые справа. Три типа входа имеют отдельную историю. По умолчанию показаны проверочные попытки Normal и Practice вместе для участков текущего плана.
- **Run progress → Filters:** необязательные фильтры **Current plan / All saved runs**, **All modes / Normal / Practice**, **Checks / Learning**. По умолчанию полноценные попытки обоих режимов учитываются вместе. Фильтры не меняют активную тренировку; **Reset** возвращает общий прогресс. Кнопка **i** объясняет исходы и надёжность.
- **Tools → Custom runs:** редактор диапазонов, подсказок и тегов с кнопкой **Pause to edit** прямо на экране. Изменение границ или дистанции входа создаёт новый участок и сохраняет старую историю.
- **Tools → Session:** ручные режимы, блоки и самооценка для уровней без автоматического плана. При активном плане здесь доступна его остановка.

HUD показывает два ряда: текущую фазу и диапазон/прогресс. Отключить его можно в настройке Show gameplay status.

## Options

Настройки по умолчанию подходят для обычного запуска. Они применяются при создании первого прохода.

| Название | Что учитывает |
|---|---|
| Trouble spots | Повторяющиеся смерти |
| Click intensity | Нажатия и короткие серии кликов |
| Mode changes | Переходы между формами |
| Earlier starts | Более ранний вход после стабильного короткого прохода |
| Break reminders | Мягкие напоминания после активной тренировки, без остановки игры |
| Memory level | Твою отметку о необходимости запоминания |

## Как считается прогресс

Первый проход собирает данные и определяет приоритеты. Один его успех не означает стабильное прохождение.

По умолчанию повторяемость требует 4 успешных попыток в полной выборке последних 6. При включённых Earlier starts затем проверяется более ранний вход. Статистика разных типов входа и Study / Verify ведётся отдельно; Normal и Practice учитываются вместе. Эти пороги — настраиваемые тренировочные ориентиры.

Когда выбранные участки удовлетворяют критериям плана, мод показывает уведомление о готовности к полным заходам. Тренировка продолжается; остановить её можно через **Pause plan**.

## Темп тренировки и перерывы

По умолчанию тренировка сохраняет одну цель и тот же StartPos до **1 минуты активной игры** либо **5 чистых успехов подряд**. В **Pace** время можно изменить от **1 до 10 минут**. Пять успехов снимают ожидание: при наличии других выбранных участков мод переходит к одному из них. Ошибка до прохождения цели обнуляет серию; смерть после уже пройденной цели сохраняет её успех. Серия относится к текущей цели и StartPos и сбрасывается при их смене. Это правило темпа; критерий Reliable в статистике остаётся отдельным.

Во втором этапе **прохождение целевого участка не перезапускает попытку**: продолжай играть до смерти или финиша. Мод продолжает считать время и клики и записывает результаты всех достигнутых участков текущего плана, даже если они сейчас не отмечены для выбора следующего старта. Пройденные участки получают Pass; смерть относится к достигнутому, но не пройденному участку. Недостигнутые участки не получают Fail, а успехи до смерти сохраняются.

Более поздние участки записываются с фактическим типом входа — с предыдущего старта или от начала уровня. Эти результаты участвуют в дальнейшем выборе задачи среди отмеченных участков. Исходный Level map продолжает показывать данные первого этапа; новые результаты видны в Run progress.

Время набирается в попытках; меню и пауза не учитываются. Автоматический выбор другой задачи или более раннего StartPos происходит только между завершёнными попытками, когда набрано время или пять успехов подряд. Пятый успех не обрывает живую попытку. **Next run** позволяет перейти раньше вручную.

Напоминание о перерыве по умолчанию появляется после **20 минут активной тренировки**, в конце попытки. Оно не ставит игру на паузу и не завершает план. В **Pace** доступны **Off / 20 min / 30 min**; для напоминаний также должна быть включена опция плана **Break reminders**.

Первый проход (**Stage 1 / Learn the level**) исключён из этих таймеров и напоминаний: здесь по-прежнему нужно один раз пройти каждый выбранный участок. Лимиты количества попыток в настройках относятся только к ручным блокам **Tools → Session**, а не к автоматической тренировке.

## Обычные попытки в оригинале

Связывание необязательно. Игра с нуля в SP-копии остаётся доступной как раньше.

1. После первого этапа открой в копии **Pause → Trainer → Original level**.
2. Введи онлайн-ID настоящего оригинала с тем же игровым маршрутом. ID из метаданных копии — только подсказка: он может относиться к другой SP-версии.
3. Нажми **Save link**, чтобы остаться в копии, или **Save & exit**, чтобы сохранить связь и выйти.
4. Открой оригинал через **Saved / Search** и играй в **Normal с 0%**. Второй план создавать не нужно.

Мод пассивно записывает новые результаты всех достигнутых участков в историю плана копии. Он не переключает старты, не запускает повтор с экрана финиша и не ставит игру на паузу. Практика, StartPos, test mode и ignore-damage в оригинале не записываются как обычные попытки с нуля.

В оригинале и копии **Stats** сразу показывает общий **Run progress**. Результаты Normal и Practice считаются вместе; вход с нуля остаётся в строке **From level beginning**. Отдельный режим можно посмотреть через **Filters**. Возрождение с чекпоинта внутри участка не засчитывает пропущенное начало. Новые результаты доступны выбору следующей задачи после возвращения в тренировку. Недостигнутые участки не получают Fail.

Для продолжения тренировки вернись в SP-копию и нажми **Continue training**. **Unlink** на странице Original level отключает связь для будущих заходов без удаления записанных результатов. Один оригинал можно связать с одним планом; связь сохраняется между запусками.

## Noclip и speedhack

Подавленная смерть (кроме служебного anticheat-объекта) и оба флага ignore damage исключают попытку из статистики. Обработчик столкновения имеет тот же приоритет, что в Blitzkrieg.

Speedhack проверяется по изменению dt между входом в цепочку scheduler-хуков и движком, а также по scheduler time scale. Обычные порталы скорости и TimeWarp-триггеры внутри уровня не являются такими изменениями. Проверка не сравнивает FPS с реальным временем и не считает лаги speedhack.

При обнаружении HUD показывает причину и Attempt excluded. Выключи помощь и начни новую попытку. Переключение обратно на x1/отключение noclip посреди попытки не возвращает её зачёт. Игра не ставится на паузу. Это относится к первому этапу, тренировке, ручным ранам и связанному оригиналу.

Результаты пройденных окон сначала собираются в памяти и сохраняются в историю при смерти, финише, рестарте или выходе. Поэтому помощь, включённая после пройденной цели, исключит всю попытку. Чистая попытка по-прежнему может продолжаться через несколько окон.

Детектор не читает настройки сторонних модов. Noclip без единого подавленного столкновения и без штатных ignore-damage флагов обнаружить этим способом нельзя. Speedhack, обходящий scheduler и его time scale, тоже может потребовать отдельной интеграции.
