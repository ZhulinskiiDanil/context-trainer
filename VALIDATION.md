# Проверка Context Trainer v0.5.0

23 сентября 2026. Windows x64, GD 2.2081, Geode 5.10.1.

## Проверено

- Сборка игрового мода через `geode build --ninja`.
- CTest: 3/3 набора, 291 проверка: 114 Training, 107 Analysis, 70 Pacing.
- Серия из пяти проходов по 1.5 секунды снимает минутное ожидание; четыре прохода не снимают его. Ошибка до цели сбрасывает серию, смерть после цели сохраняет успех. Смена цели или StartPos сбрасывает серию, но сохраняет таймер напоминания. Диагностика и некорректные попытки не дают успех для серии.
- Оригинальные попытки сохраняются в тех же историях окон с Normal / FromZero, не изменяя счётчики Practice. Проверены истинный финиш, отсутствие двойного зачёта, отказ от practice/test/StartPos/ignore-damage и незавершённая попытка при смене режима.
- Сохранены тесты непрерывного прохождения: успех на текущей цели, успехи дальше, смерть на достигнутом участке, отсутствие Fail для недостигнутых участков и использование новых исходов при выборе следующей задачи.
- По исходникам проверены сохранение связи original ID → профиль копии, защита от случайного связывания локальной копии по её ID, сохранение имени профиля и стартовых точек копии при игре в оригинале, пассивное поведение оригинала и отключение связи без удаления истории.
- В оригинале не запускается автоматическая тренировка, выбор StartPos, перерыв или replay. Создать новый автоматический план поверх связанного профиля из оригинала нельзя.

## Границы проверки

Нативный сценарий «связать копию → сыграть оригинал → вернуться в копию» внутри Geometry Dash ещё не выполнялся. Проверены модель, исходники хранения и игровых обработчиков, компиляция с установленным SDK и состав пакета. Экран Original level проверен по коду и координатам, а не кликами в игре.

Связь задаётся пользователем по онлайн-ID. Мод не угадывает оригинал по имени и не проверяет совпадение игрового маршрута через сервер; нужно выбрать соответствующий оригинал. Ранее записанные данные отдельного профиля оригинала не импортируются автоматически. После связывания новые записи идут в профиль копии.

Игра с нуля в SP-копии остаётся доступной. Старые планы и истории сохраняются; поля связи добавлены без сброса прогресса. После установки пакета нужен перезапуск игры.
